# 坦克大战 · Battle City

一个用原生 HTML + Canvas + JavaScript 实现的经典《坦克大战》网页游戏，单文件、零依赖，可直接在浏览器中运行。

## 在线试玩

部署到 GitHub Pages 后访问：`https://<你的用户名>.github.io/tank-battle/`

## 玩法

- **移动**：方向键 / `WASD`
- **射击**：空格 / `J`
- **暂停**：`P`
- **目标**：消灭所有敌方坦克，同时保护你的基地（地图底部中央的 ★），基地被毁则游戏结束

## 特色

- 三种关卡地图，含砖墙、钢墙、水域、树林等地形
- 4 种敌方坦克（普通 / 快速 / 强化 / 装甲）
- 5 种道具：火力升级 ⭐、加命 ❤️、全屏炸弹 💣、无敌护盾 🛡️、修复基地 🧱
- 移动端触屏操控、音效、粒子爆炸特效、屏幕震动

## 本地运行

直接用浏览器打开 `index.html` 即可，无需任何构建或依赖。

## 部署到 GitHub Pages

1. 仓库 Settings → Pages
2. Source 选择 `main` 分支、`/ (root)` 目录
3. 保存后稍等片刻即可通过 `https://<用户名>.github.io/<仓库名>/` 访问
